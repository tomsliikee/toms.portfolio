Project 03, GNOME Shell 50_

Small helpersin the top bar

Halo Harbor Ledge Tally Ember Torch

Extensions of my own for GNOME Shell 50 on Wayland. Each one stays small on its own, but they all follow the same rules and wear the same design: Toms Expressive Design, built on Material 3 Expressive and Google Sans Flex. No dependencies to install, no telemetry.

The extensions

Sixtools

HHalo

A top bar, a Dynamic Island, a notification center and quick settings, each one switchable on its own

GNOME Shell 50 · MIT GitHub ↵ HHarbor

A dock with pinned and running apps in ten styles, and its settings in the top bar instead of a window

GNOME Shell 50 · MIT GitHub ↵ LLedge

Desktop widgets: a clock, the load of the machine, the weather and twenty-three more, placed freely and shown over the windows from the top bar

GNOME Shell 50 · weather from Open-Meteo GitHub ↵ TTally

Shows how much of the Claude plan is used: the five-hour session as a ring in the top bar, the week and this machine's tokens in a menu

GNOME Shell 50 · data from Claude Code GitHub ↵ EEmber

Keeps Claude working with the lid closed: the screen off, every other program at rest, and the machine asleep as soon as the work is done

GNOME Shell 50 · systemd user unit GitHub ↵ TTorch

Shows which program draws the most power and how busy the machine is. One click puts a power eater to rest
